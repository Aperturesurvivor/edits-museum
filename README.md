# Edits Museum

**The greatest edits on Earth.** The Pinterest/X for edits, with American excellence front and center: founders, frontier, flight, speed and the biggest wins. Find the hardest fan-made edits and everything you need to make your own.

- **Grand Hall**: top-ranked edits, organized into genre wings.
- **Feed**: a full-screen short-form scroll, personalized by the genres you pick.
- **Armory**: a link hub of free music, SFX, footage, overlays and type. A directory, not an editor.
- **Submit**: paste a link to an edit on X; it goes into a pending review queue.

Videos play on-site, streamed straight from X's CDN (never downloaded or re-hosted). Every edit shows its creator's handle and a link to the original post. Captions are never shown.

## Run it

```bash
npm ci
npm run dev            # http://localhost:3000
# or a production preview
npm run build && npx next start -p 3100
```

Node 20+. No environment variables or accounts are needed for the default JSON backend.

| Env | Purpose |
|---|---|
| `EM_DATA_BACKEND` | `json` (default) or `supabase` |
| `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY` | Supabase backend (server-only; schema in `supabase/schema.sql`) |
| `EM_GEO_GATE` | `on` / `off`. The US-only gate is on automatically on Vercel |

## Data

- `data/edits.json`: 2,716 edits with X CDN video URLs. Generated by `scripts/export-seed.py` from raw pulls that aren't in the repo. Each edit has a `status` (`unscreened`, `flagged_review`, `flagged_medium`, `hand_kept`, `approved_by_josiah`). Excluded outright: flagged high, NSFW, non-edit, X-sensitive, and posts ruled out by hand. Everything else stays hidden until it passes visual review (below).
- Captions are kept privately for screening (`data/private/`, gitignored) and are blank in the public data. **They are never rendered.**
- `data/runtime/` (gitignored) holds the submissions queue as JSONL with the JSON backend.

## Visual review (nothing shows until it passes)

Every edit is judged from the video itself, never from post text. Open the notebook in Colab, pick a GPU, Run all:

https://colab.research.google.com/github/Aperturesurvivor/edits-museum/blob/main/notebooks/review.ipynb

- Input: `review/catalog.json` (public: id, author, X URL, MP4 URLs, duration, plus wing prototypes). Rebuild with `python3 scripts/visual-review/build_catalog.py`.
- Per edit: 8 frames from 5% to 95% of the video, ffmpeg scene-cut count, audio transcript (faster-whisper large-v3), SigLIP 2 zero-shot wing scores, and Qwen2.5-VL-7B checks (is_edit, fit, nsfw, suggestive, illegal, slur_or_hate, 0-1 per wing, confidence). Smaller models on L4/T4. Video is streamed to temp files and deleted; nothing is re-hosted.
- Checkpoints every edit to Google Drive (`MyDrive/edits-museum-review/progress.jsonl`); re-running resumes. The last cell writes `verdicts.json` and downloads it.
- Apply: `python3 scripts/ingest-verdicts.py verdicts.json` writes `data/review.json` (verdict, primary wing, 0-1 weights) and `data/private/queue.json` (low confidence / possible slurs, for a human look). Only `pass` is live; `approved_by_josiah` is always live.
- Weights = 0.6·VLM + 0.4·SigLIP per wing. Primary wing = max. An edit is listed in every wing with weight ≥ 0.5. Ranking boost = max over wings of civBoost × weight.
- Edit the notebook as `notebooks/review_pipeline.py`, then `python3 scripts/visual-review/build_notebook.py`. Local CPU smoke test: `EM_CATALOG=review/catalog.json EM_LIMIT=3 python notebooks/review_pipeline.py` (tiny models).

## Moderation

A public square for edits. Only illegal content, non-edits and NSFW are removed. Ranking blends engagement with a lean toward edits that celebrate America first, then Western civilization: freedom of speech, not freedom of reach. US-only in production.
