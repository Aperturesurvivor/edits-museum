# Edits Museum

The Pinterest/X for edits. Find the hardest fan-made edits on the internet, and everything you need to make your own.

- **Grand Hall**: top-ranked edits, organized into genre wings.
- **Feed**: a full-screen short-form scroll, personalized by the genres you pick.
- **Armory**: a link hub of free music, SFX, footage, overlays and type. A directory, not an editor.
- **Submit**: paste a link to an edit on X; it goes into a pending review queue.

Media is never re-hosted. Every edit shows its creator's handle and links to the original post, where it plays.

## Run it

```bash
npm ci
npm run dev            # http://localhost:3000
# or a production preview
npm run build && npx next start -p 3100
```

Node 20+. No environment variables or accounts are needed for v1.

## Data

- `data/edits.json`: the seed catalog (341 edits pulled from public replies/quotes to one X post). Generated by `scripts/export-seed.py` from the raw pull, which is not in the repo. Each edit has a `status` (`unscreened`, `flagged_review`, `flagged_medium`, `hand_kept`). Anything flagged high, plus posts ruled out by hand, is excluded until automated screening exists.
- `caption` holds the post text for screening and genre tagging only. **It is never rendered.**
- `data/runtime/` (gitignored) holds the submissions queue as JSONL in v1.

## Moderation

A public square for edits. Only illegal content, non-edits and NSFW are removed. Ranking blends engagement with a lean toward edits that celebrate civilization: freedom of speech, not freedom of reach.
